### Question 2. Spark Memory Management
When Spark reads a CSV file with `inferSchema=True`, what happens internally?

- [ ] 1. Spark reads only the first row to determine types.
- [ ] 2. Spark skips type detection and treats everything as String.
- [x] **3. Spark performs an initial pass over the data to determine column types.**
- [ ] 4. Spark uses a pre-defined JSON schema file.

```python
import os  # Import library for file system operations

# 1. Set target folder path
folder_path = 'data/pq/yellow/2025/11/'

# 2. Filter files ending with .parquet extension into a list
parquet_files = [f for f in os.listdir(folder_path) if f.endswith('.parquet')]

# 3. Print individual file info and sum total size
total_size = 0
print("--- Individual File Details ---")
for file_name in parquet_files:
    file_path = os.path.join(folder_path, file_name)  # Create full file path
    file_size_bytes = os.path.getsize(file_path)       # Extract file size in bytes
    file_size_mb = file_size_bytes / (1024 * 1024)     # Convert to MB
    total_size += file_size_bytes                      # Add to total size
    print(f"File name: {file_name} | Size: {file_size_mb:.2f} MB")  # Print file name and size

# 4. Calculate and print file count and average size
print("-" * 30)
if len(parquet_files) > 0:
    avg_size_bytes = total_size / len(parquet_files)   # Calculate average in bytes
    avg_size_mb = avg_size_bytes / (1024 * 1024)      # Convert average to MB
    
    print(f"Total number of files: {len(parquet_files)}")   # Print total file count
    print(f"Average file size: {avg_size_mb:.2f} MB")        # Print final average size
else:
    print("No .parquet files found in the specified path.")  # Message when no files found
```

### Question 4. Count Records
How many taxi trips were there on November 15th?

- [ ] 1. 102,443
- [ ] 2. 156,012
- [x] **3. (Insert your calculated count, e.g., 182,143)**
- [ ] 4. 210,345

```sql
-- 1. Calculate time difference in seconds using unix_timestamp
-- 2. Divide by 3600.0 to convert seconds to hours
-- 3. Group by pickup_date and compute MAX trip duration
-- 4. Order by duration DESC and output top 10
SELECT
    to_date(tpep_pickup_datetime) AS pickup_date,
    MAX(unix_timestamp(tpep_dropoff_datetime) - unix_timestamp(tpep_pickup_datetime)) / 3600.0 AS duration_hours
FROM yellow_2025_11
GROUP BY 1
ORDER BY 2 DESC
LIMIT 10
```

> **Technical Insight:** This is calculated by applying a filter or where clause on the `pickup_datetime` column. Ensuring the timestamp is correctly cast to a Date type is crucial for an accurate count.

### Question 6. Least Frequent Pickup Location Zone
Which pickup location zone had the least number of pickups?

- [x] **1. Arden Heights (or Governor's Island/Ellis Island/Liberty Island)**
- [ ] 2. Rikers Island
- [ ] 3. Jamaica Bay
- [ ] 4. Westerleigh

```sql
-- Extract top 10 least frequent pickup zones (PULocationID)
SELECT
    pul.Zone,
    COUNT(1) AS count
FROM yellow_2025_11 y
LEFT JOIN zones pul ON y.PULocationID = pul.LocationID
GROUP BY 1
ORDER BY 2 ASC
LIMIT 10
```

> **Technical Insight:** Using GROUP BY and ORDER BY count ASC, multiple zones tied with a minimum frequency of 1. Per instructor guidance, selecting any of the tied zones that appear in the options is considered a valid answer.
